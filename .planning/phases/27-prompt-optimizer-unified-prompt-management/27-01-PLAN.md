<objective>
Establish the unified Prompt Registry data foundation: three ORM models, a canonical
defaults catalog for all 9 project prompts, and a `get_prompt(key)` resolver that reads
the active DB version and falls back to the seeded default. This plan changes NO existing
builder behavior — it only adds the registry and seeds it so later plans can migrate
call sites without regressions.

Purpose: Single source of truth for every prompt, with a version chain enabling history
and rollback (F2, F4).
Output: PromptTemplate / PromptVersion / PromptOptimizationRun models, Alembic migration,
prompt_defaults catalog, prompt_registry resolver, startup seed, unit tests.
</objective>
