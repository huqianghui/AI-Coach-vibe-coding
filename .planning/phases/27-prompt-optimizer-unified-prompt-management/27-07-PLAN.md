<objective>
Add the ability to CREATE a new prompt in the unified prompt registry, so admins are no
longer limited to editing/optimizing the 9 seeded system prompts.

Purpose: Today `POST /prompts/{key}` only saves a new version of an *existing* template and
there is no way to register a new key. Admins need to add their own prompts (e.g. a new
scoring rubric prompt or a custom scenario prompt) directly from the UI.

Output: A `POST /prompts` endpoint that creates a `PromptTemplate` + active version 1, a
"新增 Prompt / New Prompt" button on the list page opening a create dialog, full unit-test
coverage (backend + frontend), and an E2E flow that creates a prompt and opens it.
</objective>
