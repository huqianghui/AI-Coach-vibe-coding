<objective>
Integrate prompt-optimizer via a Docker sidecar and a backend MCP client, exposing a
stateless `POST /api/v1/prompts/optimize` endpoint. This plan also contains the
feasibility gate: validate that the optimizer can reach Azure OpenAI through an
OpenAI-compatible `/v1` endpoint (with a LiteLLM proxy as documented fallback).

Purpose: Deliver the raw optimization capability (F1) plus the data needed to record an
optimization run later (F3). No persistence here — the endpoint only returns optimized text.
Output: sidecar in docker-compose, mcp dependency, prompt_optimizer_client, optimize API,
mock-based unit tests.
</objective>
