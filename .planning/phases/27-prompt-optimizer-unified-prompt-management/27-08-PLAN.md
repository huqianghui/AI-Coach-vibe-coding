<objective>
Let admins read the full text of any historical prompt version from the detail page.

Purpose: The version history list currently shows only version number, source, active badge,
timestamp and a rollback button — the actual text of older versions is invisible. The
`GET /prompts/{key}/versions` response already includes each version's `content`, so this is a
frontend-only enhancement: add a read-only "查看内容 / View content" affordance per version.

Output: Each version row gains a "View content" action that opens a read-only dialog (or inline
expander) rendering that version's content, plus its source and note. Unit test + E2E coverage.
</objective>
